# 订阅家 · Dingyuejia

[订阅家](https://dingyuejia.com/)是一个中文 AI 会员订阅比价网站，收录 ChatGPT、Claude、Gemini 等服务的第三方商家报价。选择套餐后，可以比较人民币价格、库存、充值方式、到账时间和售后，并查看报价更新时间及历史走势。

## 报价怎么读

套餐页将官方美元标价与第三方商家的人民币报价分别列出。当前最低价和最高价根据有库存的人民币报价计算。最终价格、交付条件及退款条款以商家结算页为准，订阅家不经手付款。详见[比价方法与数据来源](https://dingyuejia.com/methodology)和[交易风险说明](https://dingyuejia.com/disclaimer)。

## English overview

Dingyuejia is a Chinese-language comparison site for AI subscription offers. It lists third-party merchant prices in CNY alongside reference prices from the providers in USD. Plan pages show stock status, delivery details, and historical price records. Purchases are handled by the individual merchants.
